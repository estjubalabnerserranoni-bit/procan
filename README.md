Antecedentes 
En los mercados muchos comerciantes realizan diariamente actividades como el control de productos, registro de ventas, manejo de precios y administración de sus ingresos. Sin embargo, una parte de estas actividades todavía se realiza de manera manual, utilizando cuadernos hojas de papel o métodos que no permiten organizar la información de forma rápida y eficiente. 
Esta situación puede ocasionar dificultades para conocer la cantidad de productos disponibles llevar un control adecuado de las ventas, identificar los productos más vendidos y mantener actualizada la información del negocio. 
Ante esta problemática surge la necesidad de desarrollar una aplicación informática que brinde apoyo a los comerciantes del mercado La Cancha permitiéndoles organizar y controlar de manera más sencilla la información relacionada con sus productos y ventas. La aplicación busca utilizar la tecnología como una herramienta de apoyo para mejorar la administración de los pequeños negocios y facilitar las actividades que los comerciantes realizan diariamente. 
Contexto 
El proyecto se desarrolla en el contexto de los comerciantes que trabajan diariamente en los mercados quienes necesitan administrar diferentes aspectos de sus negocios como sus productos, precios, ventas, cantidades disponibles e ingresos. Para muchos comerciantes llevar un control organizado de esta información puede resultar complicado debido a que utilizan métodos tradicionales como cuadernos hojas de cálculo o registros manuales. 
Además los comerciantes necesitan consultar y actualizar su información de manera rápida mientras realizan sus actividades diarias. La falta de una herramienta sencilla y adaptada a sus necesidades puede dificultar la organización del negocio y aumentar la posibilidad de cometer errores en los registros. 
Por esta razón el proyecto propone desarrollar una aplicación que permita a los comerciantes gestionar de manera más organizada la información de sus negocios. La aplicación estará orientada a ser práctica, fácil de utilizar y adecuada para las necesidades de los comerciantes del mercado contribuyendo a mejorar el control de sus actividades comerciales. 
Situación actual 
Muchos comerciantes de los mercados llevan el control de sus productos y ventas de forma manual utilizando cuadernos, hojas o simplemente confiando en la memoria esto puede dificultar el seguimiento de las ventas el control de la cantidad de productos disponibles y la actualización de los precios. Como consecuencia pueden presentarse errores en los registros pérdida de información y dificultades para conocer con exactitud el estado del negocio. Actualmente tengo problemas de organización en los puestos de mi madre en el mercado y si de por sí ya tengo un sistema para mantener los puestos organizados y aun así siguen mal como serán los demás 
Personas o sectores afectados 
Los principales afectados son los comerciantes de los mercados especialmente aquellos que administran sus negocios de manera independiente y necesitan controlar constantemente sus productos y ventas e ingresos. También pueden verse afectados los clientes ya que una mala organización del negocio puede ocasionar confusiones con los precios disponibilidad de productos o atención al momento de realizar una compra. 
Relevancia del problema: 
Este problema es relevante porque una buena organización de la información puede ayudar a los comerciantes a administrar mejor sus negocios reducir errores y ahorrar tiempo. El desarrollo de una aplicación dirigida específicamente a los comerciantes del mercado puede proporcionar una herramienta sencilla para registrar y consultar información de manera rápida y organizada. De esta forma el proyecto busca contribuir a la modernización de los pequeños negocios y facilitar el uso de la tecnología en las actividades comerciales. 
Objetivos Específicos 
-	Diseñar: una interfaz sencilla e intuitiva que permita a los comerciantes utilizar la aplicación de manera fácil y rápida. 
-	Implementar: un sistema de registro de productos que permita almacenar información como nombre, precio y cantidad disponible. 
-	Desarrollar: una función para registrar y controlar las ventas realizadas por los comerciantes. 
-	Incorporar: un sistema de actualización de productos y precios que permita mantener la información del negocio organizada y actualizada. 
-	Implementar: funciones de consulta que permitan al comerciante visualizar de manera rápida la información de sus productos y ventas. 
-	Reducir: los errores ocasionados por el registro manual de información mediante la automatización de las principales actividades de control del negocio. 
 
Algoritmo Principal del Proyecto: 
Inicio 
1.	Iniciar la aplicación. 
2.	Mostrar el menú principal. 
3.	El comerciante selecciona una opción: 
a.	Registrar producto. 
b.	Consultar productos. 
c.	Actualizar producto. 
d.	Registrar venta. 
e.	Consultar ventas. 
f.	Consultar información del negocio. 
g.	Salir. 
4.	Si selecciona Registrar producto: 
a.	Solicitar nombre del producto. 
b.	Solicitar precio. 
c.	Solicitar cantidad disponible. 
d.	Validar los datos ingresados. 
e.	Guardar el producto. 
f.	Mostrar mensaje de confirmación. 
5.	Si selecciona Consultar productos: 
a.	Mostrar la lista de productos registrados. 
b.	Mostrar nombre, precio y cantidad disponible. 
6.	Si selecciona Actualizar producto: 
a.	Solicitar el producto que desea modificar. 
b.	Permitir modificar sus datos. 
c.	Guardar los cambios. 
d.	Mostrar mensaje de confirmación. 
7.	Si selecciona Registrar venta: 
a.	Seleccionar el producto vendido. 
b.	Solicitar la cantidad vendida. 
c.	Verificar que exista suficiente stock. 
d.	Calcular el total de la venta. 
e.	Actualizar la cantidad disponible. 
f.	Registrar la venta. 
8.	Si selecciona Consultar ventas: 
a.	Mostrar las ventas registradas. 
b.	Mostrar los productos vendidos y los ingresos obtenidos. 
9.	Si selecciona Consultar información del negocio: 
a.	Mostrar un resumen de productos, ventas e ingresos. 
10.	Regresar al menú principal para permitir realizar otra operación. 
11.	Si el comerciante selecciona Salir: 
•	Guardar la información. 
•	Cerrar la aplicación. 
12. Fin. 
 
Investigación y Justificación Tecnológica 
Para el desarrollo de la aplicación se seleccionará C# como lenguaje de programación principal utilizando Windows Forms para la creación de la interfaz gráfica 
C# 
C# es un lenguaje de programación desarrollado por Microsoft y orientado a la creación de diferentes tipos de aplicaciones nos permitirá trabajar con programación orientada a objetos, interfaces gráficas, bases de datos y diferentes herramientas de desarrollo. 
Para este proyecto en C# resulta adecuado porque la aplicación estará dirigida a los comerciantes del mercado y necesitará una interfaz sencilla que permita registrar productos, controlar cantidades, registrar ventas y consultar información del negocio. 
 	 
Características del proyecto  
La aplicación tendrá diferentes funcionalidades que requieren manejar información y realizar operaciones de forma organizada. C# permite utilizar clases, objetos, métodos y eventos, lo que facilita dividir el sistema en diferentes componentes y mantener el código organizado. 
Posibilidades futuras 
La elección de C# también permite ampliar el proyecto posteriormente. Por ejemplo se podría incorporar una base de datos que estamos avanzando también, para almacenar permanentemente los productos y ventas, generar reportes, agregar usuarios, implementar un sistema de inicio de sesión o desarrollar nuevas funciones para mejorar la administración del negocio.

Justificación final 
Se selecciona C# porque sus características se adaptan a las necesidades del proyecto y permiten desarrollar una aplicación de escritorio funcional para apoyar a los comerciantes del mercado. Además su facilidad para trabajar con interfaces gráficas programación orientada a objetos y bases de datos proporciona una base tecnológica adecuada para el desarrollo actual y para futuras mejoras del sistema.
